# Workflow: audit-reporting

1. **Scan Tasks**:
   - Read all files in `docs/audit_tasks/`.
   - Identify tasks marked as "COMPLETED" or "IN-PROGRESS".

2. **Verify Reports**:
   - Check if a report is linked in the task file.
   - Verify the existence of the report file in `docs/dev_logs/reports/`.

3. **Check Content**:
   - Ensure the report contains a "Verification Results" or "Outcome" section.

4. **Remind Lead**:
   - If a report is missing, flag it to the Lead Architect for reassignment.
