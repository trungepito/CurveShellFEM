# Development Logs: CurveShellFEM

This directory contains the technical history, agent session logs, and the consolidated knowledge base for the CurveShellFEM project.

## Structure
- **`index.md`**: Master timeline of all development phases.
- **`sessions/`**: Atomic logs for every major task (prefixed by date).
- **`knowledge_base/`**: Deep-dive technical documentation (Math, Physics, Optimization).
- **`agents/`**: Profiles of AI agents involved in the project.

## Contribution Workflow
Agents should create a new session log for every major phase or significant technical pivot. Key insights should be promoted to the `knowledge_base/`.
