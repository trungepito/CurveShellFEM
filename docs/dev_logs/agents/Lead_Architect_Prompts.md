> "We are moving into Phase 26: Large Strain Integration. Please use the `/manage-project` workflow to break this down into tasks for the Implementation, Analyst, and Validation agents. Update the `PROJECT_ROADMAP.md` accordingly."

> "We need to finish the Arc-Length refactoring. Please `/sync-agents` to ensure that Antigravity is implementing the modular constraints, the Validation Scientist is preparing the snap-through benchmarks, and the Analyst is verifying the Crisfield formulation."

## 4. Quality Audit
> "Conduct a project-wide quality audit. Check if the Dev Logs are up to date and if the documentation in `docs/` correctly reflects the Phase 25 implementation status."

## 5. Strategic Decision
> "Based on the recent convergence failures, should we prioritize 'Adaptive Mesh Refinement' or 'Advanced Kinematic Hardening' for Phase 27? Provide a strategic recommendation based on our long-term roadmap."
